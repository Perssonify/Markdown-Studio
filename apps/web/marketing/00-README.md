# Markdown Studio — marketing kit

Ready-to-use copy for **[markdownstudio.com](https://markdownstudio.com)**, built by
[Perssonify Labs](https://labs.perssonify.com/).

Everything here describes features that **exist in the product**, checked
against the code after v1.77.0. Nothing is aspirational; if a claim is in here,
you can demonstrate it in the app today. Where a limitation matters to a buyer,
it is stated plainly in `06-faq.md` rather than hidden — that is deliberate, and
it is what makes the rest of the claims credible.

## The one-paragraph version

> Markdown Studio is a dual-pane Markdown editor: raw Markdown on the left,
> formatted rich text on the right, always in sync — edit either side. It keeps
> your documents in your browser, with no account and no copy on a server,
> handles math, diagrams, tables and task lists, links notes together with
> `[[wiki links]]` and draws the result as a relationship map, and exports to
> Markdown, HTML, Word, PDF or JSON. Free, offline-capable, and embeddable in
> your own product.

## Before you publish

- Replace `markdownstudio.com` links if you stage the site elsewhere first.
- Privacy wording follows `07-messaging-guide.md`: say "your documents stay in
  your browser" or "no server stores or reads your documents" — never "nothing
  leaves your device" or "nothing is uploaded". Importing from a URL can go
  through our server (with the user's consent), and images in a document load
  from wherever they are hosted.
- Screenshots: the app's own light/dark themes are both presentable — take
  matched pairs so the site can swap them with the visitor's theme.
- The product name is **Markdown Studio** (two words, both capitalised). The
  npm package is still `@perssonify/editor`; that is a developer coordinate, not
  a brand, and only belongs in developer-facing copy.
